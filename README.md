## What it does

`main.ts` scores a shortlist of candidate words against the judge's five
published criteria — funny at first sight, humour from the word itself,
freshness, and exactness, in that order — and writes the winner to
`/output/entry.txt`: a single word, nothing else attached.

The winner is the longest word in the dictionary:

**pneumonoultramicroscopicsilicovolcanoconiosis**

Deleting it is the joke itself. The dictionary loses its longest word, the
gap it leaves is the biggest one in the language, and nobody alive can spell
it twice anyway.

## Run it

```sh
node main.ts
```

It needs nothing installed and reads nothing from the network, the clock, or
the environment. The same run always writes the same word.
